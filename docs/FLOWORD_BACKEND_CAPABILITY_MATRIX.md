## UI-to-execution traces

- **OmniRoute:** provider UI → Next route `/api/providers*` → validation/model layer → local credential DB/provider API.
- **MediaCrawler:** crawler UI → MediaCrawler HTTP → `CrawlerManager` → `uv run python main.py` → files under `data/`.
- **Youwee:** React page → Tauri invoke → embedded `be-youwee` Rust command → yt-dlp/FFmpeg/Whisper → output file/events.
- **OpenMontage:** ArtCraft page → direct Backlot HTTP/SSE → state derived from project/checkpoint/artifact files. Backlot observes; it does not execute a generic render job.
- **Story Studio:** `PageInkOS` → Tauri lifecycle commands → local InkOS Studio Hono API → `@actalk/inkos-core` agents/pipeline → project artifacts.
- **Vynaro:** embedded React route → typed `ipc/commands.ts` → Tauri command → Vynaro Rust crates → FFmpeg/provider/filesystem.
- **Image Editor:** PageDraw handler → `PageDrawAdapter` → Tauri API → ArtCraft Rust generation/background-removal command; manual canvas actions stay in Konva/frontend.

## Canonical capability ownership

- AI routing, models, providers and credentials: **OmniRoute**.
- Social research/crawling: **MediaCrawler**.
- URL media search/download/metadata/subtitles: **Youwee**.
- Story/book/script/storyboard domain: **InkOS**.
- Local video analysis, scene detection, TTS and composition primitives: **Vynaro**, subject to runtime comparison with the current Floword Rust caption pipeline.
- Montage project observation/checkpoints/library: **OpenMontage**; render execution remains Vynaro/CapCut-owned until an OpenMontage executor is found.
- AI image jobs: **ArtCraft Rust Image Engine**; interactive pixel/canvas editing remains **PageDraw**.
- Draft/render automation: **CapCut Mate**, with CapCut Automation UI kept separate.

## Reality constraints and blockers

- MediaCrawler uses **NON-COMMERCIAL LEARNING LICENSE 1.1** and has one singleton process, not durable job IDs or percentage progress.
- Youwee and Vynaro have real embedded Rust capabilities but no Unified Gateway-callable server. A minimal local IPC/sidecar bridge is required; source existence is not gateway readiness.
- Provider management must be local-only and must preserve OmniRoute management auth without returning raw API keys.
- Python gateway artifacts and the Rust `ArtifactStore` do not yet share a registration bridge.
- Existing app UIs remain for reference/debug until each Floword replacement action passes end-to-end.
